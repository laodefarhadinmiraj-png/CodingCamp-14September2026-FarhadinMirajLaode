# Expense & Budget Visualizer

Aplikasi web sederhana untuk mencatat pengeluaran harian, melihat total balance, dan visualisasi pie chart pengeluaran per kategori.

## Fitur Utama (MVP)
- Form input transaksi (Item Name, Amount, Category: Food/Transport/Fun) dengan validasi
- Daftar transaksi (scrollable) + tombol Delete
- Total Balance otomatis update
- Pie chart (Chart.js) otomatis update

## Optional Challenges yang Diimplementasikan
- ✅ Sort transaksi (Newest / Amount / Category)
- ✅ Highlight spending over a set limit
- ✅ Dark/Light mode toggle

## Tech Stack
- HTML, CSS, Vanilla JavaScript (tanpa framework)
- Chart.js (CDN) untuk pie chart
- Browser Local Storage API (tanpa backend)

## Cara Menjalankan
Cukup buka `index.html` di browser, atau publish via GitHub Pages.
